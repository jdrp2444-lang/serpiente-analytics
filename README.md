# Serpiente + Google Analytics 4

Juego web de Serpiente creado para una práctica de Google Analytics.

## Ejecutar el proyecto

Abrir la carpeta con Visual Studio Code y ejecutar `index.html`
con la extensión Live Server.

## Google Analytics

El ID de medición debe pegarse en:

`js/analytics.js`

Reemplazar:

`G-XXXXXXXXXX`

por el ID real de Google Analytics 4.

## Eventos registrados

- `game_start`
- `food_eaten`
- `game_pause_or_resume`
- `game_resume`
- `game_over`
